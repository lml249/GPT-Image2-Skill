# Additional reusable template catalog

This is a compact adaptation of selected entries from the upstream [awesome-gpt-image-2 template library](https://github.com/freestylefly/awesome-gpt-image-2/blob/0dc09c46c8a30b1fdd89c18cc78a894dac2104e/docs/templates.md). It adds routing and fillable structure without importing the upstream website, API, case images, or full 541-case data set. Use one entry only when the request matches it; preserve exact user copy and label unverified specifications as conceptual.

## UI screenshot

Use for a concrete iOS, Android, web, dashboard, or social screen. Required: platform, viewport/aspect ratio, navigation chrome, 3–5 content modules, exact visible copy, theme colors. Prompt: `Create one high-fidelity [platform] UI screenshot for [product]. Use [layout], [theme], and [palette]. Include exactly these readable labels: [copy]. Keep spacing, icon alignment, hierarchy, and [aspect ratio] consistent; no extra tabs, placeholder text, or mixed platforms.` Avoid a vague “modern app” brief and unconstrained filler text.

## Infographic engine

Use for explainers, timelines, flows, or knowledge cards. Required: audience, title, 3–5 modules, relationship/arrows, short labels, palette. Prompt: `Create a [format] infographic about [topic] for [audience]. Organize [N] modules as [flow/timeline/comparison], with [relationship] shown by arrows and color groups. Use short readable labels [labels], [palette], generous spacing, and no long paragraphs or decorative clutter.`

## Poster layout

Use for a finished campaign, event, film, or cover poster. Required: headline, subject, hierarchy, aspect ratio, palette, intended use. Prompt: `Create one finished [use] poster for [subject]. Make the exact headline “[TITLE]” dominant, with [one short supporting line]. Use [composition], [palette], [mood], and [aspect ratio]. Keep the visual hierarchy clear; no moodboard, process sheet, unrelated text, or copied logos.`

## Product commerce visual

Use for product hero shots, packaging, or sales detail pages. Required: product and selling point, material, camera angle, scene, lighting, copy limits. Prompt: `Create a commercial product visual for [PRODUCT]. Show [angle] with [material] in [scene], lit by [lighting]. Make [selling point] the focus and include only the exact copy “[COPY]”. Separate the hero product from supporting props; no random packaging claims, extra brands, or clutter.`

## Brand identity package

Use when a brand needs a coherent identity direction rather than a single logo. Required: business, audience, personality, competitors, references, touchpoints. Prompt: `Develop a conceptual brand identity board for [BRAND], a [BUSINESS] for [AUDIENCE]. Show three distinct logo directions, a restrained color system with HEX values, typography roles, and applications on [TOUCHPOINTS]. Explain the visual logic briefly. Treat all marks as concept directions; do not imply trademark clearance or production-ready vector files.`

## Architecture and space

Use for interior, exterior, or spatial visualization. Required: building type, viewpoint/lens, materials, lighting/time, circulation, known dimensions. Prompt: `Render a [SPACE] from [VIEWPOINT] with [materials] and [lighting/time]. Show [required zones] with believable scale, perspective, circulation, and shadow behavior. Include only confirmed dimensions [facts]; mark any proposed values as conceptual. Avoid impossible structure, random signage, and inconsistent vanishing points.`

## Realistic photography

Use when the target is a believable captured photograph. Required: subject, camera/lens, light source, environment, depth of field, intended editorial/use context. Prompt: `Create a realistic photograph of [SUBJECT] in [PLACE], captured as if with a [camera/lens] at [lighting]. Specify [framing], depth of field, material/skin texture, and intended use [editorial/product/documentary]. Keep anatomy, reflections, and light physically coherent; no CGI polish, watermark, or invented brand text.`

## Character design sheet

Use for a consistent character with turnarounds, expressions, or costume details. Required: age/adult status, identity traits, outfit, views, expression count, palette, safety boundaries. Prompt: `Create a character design sheet for [ADULT CHARACTER]. Keep face, hairstyle, proportions, outfit, and accessories consistent across [views]. Include [N] labeled expressions and [detail callouts], arranged on a clean [aspect ratio] sheet. Use [style/palette]; no extra characters, costume drift, or unreadable filler labels.`

## Document and publishing visual

Use for a single editorial spread, menu, brochure page, or publication mockup. Required: document type, grid, margins, hierarchy, exact headline, image/text regions, language. Prompt: `Create one polished [DOCUMENT TYPE] visual with a [N]-column grid, [margins], and clear headline/body/caption hierarchy. Set the exact headline “[HEADLINE]”; use simulated body text unless exact copy is supplied. Show [image/table/modules] with [style/palette]. This is a visual layout concept, not an editable document or proof of typographic correctness.`
