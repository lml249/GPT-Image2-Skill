# Adapted template sources and license

The four reusable templates are adapted from [freestylefly/awesome-gpt-image-2](https://github.com/freestylefly/awesome-gpt-image-2/tree/b477278bb2a36d4c59655eb0daa4ce48e8dbc4c4), revision `b477278bb2a36d4c59655eb0daa4ce48e8dbc4c4`. Each template records its relevant section, actual example case, and the author credited by that repository. Originality labels on the existing 162 gallery cases are unchanged; the four templates are counted separately.

Adaptations add explicit inputs, CLI-aligned canvas defaults, exact-copy constraints, and boundaries for conceptual science/engineering and brochure image outputs. No third-party example images are bundled here.
