# 🕹️ Pixel Art

Range: No. 52–53 · Count: 2

Load this file only when the request matches this category. For cross-cutting writing rules, pair it with `craft.md`.

## Selection notes

- Use when: A small pixel scene or sprite sheet whose pixels remain distinct.
- Necessary inputs: Subject, view, frame arrangement, pixel scale, and limited palette.
- Style / scene tags: pixel art, sprites; game assets, still life; 像素.
- Typical failures: Blurred/resampled pixels; changing scale or lighting across sprite frames.
- Related cases in this file: No. 52, No. 53.
